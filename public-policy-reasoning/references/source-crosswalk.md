## Source-grounded construct

**SOURCE:** QAA's Public Policy and Public Administration benchmark describes public decision-making systems, governance, public policy, public administration, public management, policy formulation and implementation, public-service delivery, impact evaluation, and lessons for future action. NASPAA identifies competencies in public leadership, policy participation, critical analysis and evidence-informed decisions, public-service perspective, and productive culturally responsive communication. NASPAA Standard 5 links competencies to observable evidence, assessment, and continuous improvement.

## Degree-level boundary

**SOURCE:** QAA is a sector-led subject benchmark and NASPAA is an accreditation framework for public-service programs.  
**INFERENCE:** A proposed advanced public-policy competency includes diagnosis, policy design, implementation, evaluation, public communication, stakeholder stewardship, and learning from consequences.  
**NOT CLAIMED:** These documents are a universal PhD standard; NASPAA is primarily MPA / MPP accreditation.

## Construct decomposition

1. Define a public problem and its affected populations.
2. Map institutions, incentives, stakeholders, power, values, and evidence.
3. Formulate feasible policy options with assumptions and tradeoffs.
4. Analyze implementation, resources, administrative capacity, and risks.
5. Evaluate effects, distributional consequences, and uncertainty.
6. Communicate across technical, public, and decision audiences.
7. Use results for improvement while preserving public accountability.

## Evidence and task model

**CROSSWALK:** Problem diagnosis, stakeholder map, evidence ledger, options matrix, implementation plan, evaluation design, public communication artifact, and post-decision learning memo.  
**EVALUATOR DESIGN:** Score problem framing, evidence fit, options quality, feasibility, equity / distributional analysis, communication, and explicit value judgments.

## Textbook spine

`Diagnose → Map system and stakeholders → Build options → Test implementation → Evaluate consequences → Communicate → Learn and revise`

## Failure modes and constraints

- policy preference disguised as evidence;
- stakeholder list without power or consequence analysis;
- feasible option omitted;
- benefits counted without burdens;
- implementation treated as automatic;
- public values suppressed rather than surfaced;
- agent recommendation mistaken for accountable public judgment.
