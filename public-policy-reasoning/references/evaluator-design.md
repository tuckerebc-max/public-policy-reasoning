## `OPT-67-PUBLIC-POLICY` evaluator

**Primary evidence:** problem definition, affected-population map, stakeholder / power map, evidence ledger, options matrix, implementation and evaluation plans, public brief, learning memo.

**Dimensions:** problem framing; evidence fit; stakeholder coverage; feasibility; implementation; equity / burdens; communication; explicit values; accountability; improvement.

**Critical failures:** hidden value judgment, omitted affected population, feasibility blindness, or agent output presented as public decision authority.

**Challenge set design:** contested values; incomplete evidence; implementation barrier; distributional tradeoff; missing-stakeholder case; post-decision evidence requiring revision.

**Improvement loop:** diagnose weak stakeholder or consequence analysis → revise prompt with burden and implementation requirements → rerun → compare option quality and uncertainty disclosure.
