# `OPT-67-PUBLIC-POLICY` textbook-skill architecture

**Architecture ID:** `F2-ARCH-67-PUBLIC-POLICY-001`  
**Status:** `SPEC_DRAFT — DEGREE-LEVEL BOUNDARY VISIBLE`  
**Promise:** Teach evidence-informed public decision making while keeping values, implementation, distributional effects, and accountability visible.

## Learner change

Before: the learner recommends a preferred policy.  
After: the learner diagnoses a public problem, maps affected parties and institutions, compares feasible options, anticipates consequences, communicates across audiences, and learns from implementation.

## Progression

`Diagnose → Map → Formulate → Implement → Evaluate → Communicate → Improve`

## Unit map

| Unit | Work | Learner evidence |
|---|---|---|
| 1 | Problem definition and affected populations | problem statement and boundary map |
| 2 | System, stakeholder, and power analysis | stakeholder / system map |
| 3 | Evidence appraisal and options | evidence ledger and options matrix |
| 4 | Implementation, resources, and risks | implementation plan |
| 5 | Evaluation, equity, and consequences | evaluation / distributional memo |
| 6 | Public communication and learning | public brief and post-decision review |

## Source boundary

QAA supplies a field-level taught-subject benchmark. NASPAA supplies an accreditation-level competency and continuous-improvement frame for public-service programs. Neither is presented as universal PhD consensus.

## Human-plus-agent design

The agent may summarize supplied evidence and generate options for review. The human identifies values, affected groups, evidence limits, public accountability, and the final decision boundary.

## Evaluator seed

Dimensions: problem framing, evidence fit, stakeholder / power awareness, option quality, implementation feasibility, equity and burden analysis, communication, transparency of value judgments, and learning loop.

## First drafting packet

Draft `POLICY-001` will compare two plausible interventions using incomplete evidence and conflicting stakeholder priorities. It will require a recommendation plus an explicit statement of what cannot be known yet.
